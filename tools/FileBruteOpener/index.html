File Security Analyzer & Authorized Password Recovery Lab

Educational tool for identifying file encryption and recovering access to your own password-protected files.

For authorized use only: files you own, or where you otherwise have explicit permission to attempt recovery. Searches are bounded to a known password, a finite dictionary, or a capped mask keyspace — there is no unrestricted brute-force mode.

Dictionary: try each password you list, one per line - use this when you have a shortlist of guesses. Mask: try every combination of a charset up to a fixed length (e.g. all 4-digit PINs) - use this when you know the password's shape but not its value. Both are finite by design: there's no unbounded/open-ended brute-force mode here.

Test-file generator (educational demonstrations)

Generates valid encrypted files for a password you choose, so you can try the verifier and search above against a real file — these also open correctly in standard PDF/ZIP tools. (WinZip AES-192 test files can't be generated here because browsers' Web Crypto API doesn't support 192-bit AES keys at all — verification of real AES-192 files is unaffected, since that check only needs PBKDF2 and HMAC-SHA1, no AES operation.)
