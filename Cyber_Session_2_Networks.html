IP = Internet Protocol. This is IPv4. Ask: "Can two houses on one street have the same number?" No. Same for IPs on one network.

MAC address

3C:84:6A:1F:9B:20

Maker (who built the card)

Device (this one card)

Your network card's name tag. Set at the factory.

MAC = Media Access Control. 48 bits, written in hex (0-9, A-F). The first half is the manufacturer ID (OUI). Phones now randomise their Wi-Fi MAC for privacy.

Who am I on the network?

Set up

  • Pairs at each PC. No PC? Phone: Settings > About phone > Status (Android) or Settings > Wi-Fi > (i) (iPhone) shows IP and router.
  • Windows: press Win, type cmd, Enter.
  • Linux: Ctrl+Alt+T.
  • Click each target on screen as the room finds it. All five = confetti.

What to look for

  • Windows: in ipconfig find the "Wireless LAN adapter Wi-Fi" or "Ethernet adapter" block. Ignore "Media disconnected" ones.
  • IPv4 like 192.168.x.x = private. Default Gateway = the router.
  • ipconfig /all: Physical Address (e.g. 3C-84-6A-...) is the MAC.
  • Linux: ip a look under wlan0/wlp*/eth0/enp*. If resolvectl is missing use cat /etc/resolv.conf.
  • curl is built into Windows 10/11. Or browse to ifconfig.me.
  • Click a command on screen to copy it.

Are you there?

>ping 8.8.8.8time = ms
>ping google.comDNS + ping
>tracert google.comcount the hops
>nslookup google.comask DNS
$ping -c 4 8.8.8.8time = ms
$ping -c 4 google.comDNS + ping
$traceroute google.comcount the hops
$nslookup google.comask DNS

Who in the room gets the lowest ms?

  • ping = sonar: send an "echo request", wait for "echo reply". Time in milliseconds.
  • 8.8.8.8 is Google's public DNS server.
  • tracert / traceroute lists every router (hop) on the road. Rows of * * * are routers that don't answer: normal.
  • Linux: if traceroute is missing, use tracepath google.com. Ctrl+C stops a running ping.
  • Some networks block ping. If 8.8.8.8 times out, try the gateway IP.

The OSI model

7 layers. One parcel.

Please Do Not Throw Sausage Pizza Away

1Physicalcables, Wi-Fi radio
2Data LinkMAC, switches
3NetworkIP, routers
4TransportTCP / UDP, ports
5Sessionkeeps the chat open
6Presentationencryption, formats

Builds bottom-up. Map it to today: MAC = layer 2, IP = layer 3, ports = layer 4, HTTP = layer 7. Wireshark shows exactly these layers.

Install

  • Windows: wireshark.org installer, tick Npcap. No interfaces listed = Npcap missing or not admin.
  • Linux: sudo apt install wireshark, answer Yes to non-root capture, then sudo usermod -aG wireshark $USER and log out/in. Quick way: sudo wireshark.

HTTP = the language of the web. Every page, every app update, every Instagram scroll is a request and a response.

The server replies with a number

200OKHere you go.
301MovedGo over there.
403ForbiddenNot for you.
404Not foundNo such page.
500Server errorThe server broke.
2xx good, 3xx redirect, 4xx your fault, 5xx server's fault.
